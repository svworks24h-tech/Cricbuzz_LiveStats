# 3-Minute Demo Script

1. Open Home: show project title, KPIs and technology stack.
2. Open Live Matches: show live API configuration/fallback and match table.
3. Open Top Player Stats: show batting, bowling and performance analytics.
4. Open SQL Analytics: select Q21 to demonstrate advanced weighted ranking, then Q23 for window-function recent form, then Q25 for quarterly trajectory.
5. Open CRUD Operations: create a player, update it, show it in Read, then delete it; demonstrate match status update.
6. Finish by showing the project folder, README and database schema.
